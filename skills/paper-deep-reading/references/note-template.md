# 精读笔记模板

每篇论文一份精读笔记，8 个字段固定不变（标题逐字使用，便于检索与工具处理）。用户说"出笔记"或读完确认后，按下述规范填写。

## 各字段填写规范

**问题**：这篇论文解决什么问题？现有方法差在哪？2–4 句，写"为什么值得解决"，不抄摘要。

**核心贡献**：列出论文真正的新东西（通常 1–3 条）。区分"论文声称的贡献"和"实际的贡献"。

**方法拆解**：核心思路的分步拆解，给直觉。每步回答"这步在干嘛、为什么需要这步"。可用编号列表或小图。

**关键公式与直觉**：只放最核心的 1–3 个公式。每个公式：逐符号说清来源 → 一句人话直觉 → 每步推导"凭什么"（硬核模式的产物直接填这里）。

**实验与证据强度**：主要实验结果 + 按批判清单（见 `critical-checklist.md`）核出的证据强度：撑得住 / 要打折 / 存疑。

**局限与质疑**：作者自己承认的局限 + 你的批判（标注严重度：致命 / 重要 / 疑问，落在具体位置）。

**与我读它的目的的关系**：回到诊断时问的"为什么读这篇"——读完之后，用户的目的达成了吗？下一步读什么/做什么。

**延伸阅读**：值得接着读的 2–4 篇（前身工作、直接后续、竞争方案），各配一句"读它能补什么"。

## 空白骨架（直接复制使用）

```markdown
# 精读笔记：<论文名>

> 读它的目的：（诊断时记录，填"与我读它的目的的关系"时回看）

## 问题

## 核心贡献

## 方法拆解

## 关键公式与直觉

## 实验与证据强度

## 局限与质疑

## 与我读它的目的的关系

## 延伸阅读
```

成品示例见 `examples/attention-is-all-you-need-notes.md`。
