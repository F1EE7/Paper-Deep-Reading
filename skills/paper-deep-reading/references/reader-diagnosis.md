# 背景诊断与最小前置包

对应三遍法第二遍的"讲解之前先诊断"。原则：**先诊断，再讲解**。缺什么补什么，不整段重讲。

## 一、诊断问题库

精读开始前（或用户卡住时）从中选问，一次最多 3 问，不要问卷式轰炸：

1. **目的**：你为什么读这篇？（课程要求 / 组会汇报 / 找自己课题的切入点 / 纯好奇）——决定深度与侧重
2. **背景**：这个领域你读过别的论文吗？哪篇？
3. **前置课**：论文用到的核心工具（如 attention、变分推断、凸优化）你学过吗？
4. **卡点类型**：是整段看不懂，还是某个符号/某句英文/某个图表看不懂？
5. **已有理解**：用自己的话说说，你觉得这篇在干嘛？（哪怕是错的，也是校准起点）
6. **时间预算**：今晚要讲给别人听，还是这周慢慢啃？

第 5 问最重要：让用户先说，而不是你先讲。

## 二、最小前置包方法

诊断出前置缺口后：

- **只补卡住的那一块**：缺口是"不知道 softmax"就只讲 softmax，不重讲整个神经网络。
- **一个直觉 + 一个最小例子**：每个前置概念配一个生活直觉或 2 行的小例子，够用即止。
- **当场回填**：补完后立刻回到刚才卡住的那句话重读一遍——用户能自己读通才算补完，然后继续正文。
- **记录**：哪个概念补过、用什么讲法有效，写入记忆（`memory/paper-deep-reading/`），下次同类缺口直接复用。

反模式（禁止）：把用户没问的背景知识从头到尾铺一遍；用"你先去学 XX"打发用户。

## 三、输入降级策略（诚实边界）

信息不完整时，**明示边界，禁止编造**：

| 情况 | 降级动作 |
|---|---|
| arXiv/DOI 链接只有摘要页，全文抓不到 | 明说"现在只基于摘要+图表说明"；速览卡照出，但【证据】栏标注"仅来自摘要"；请用户粘贴关键节或给 PDF 路径 |
| PDF 解析不完整（公式/图表乱码） | 指出哪些节解析失败；请用户截图那几页；分批推进能读的部分 |
| 用户只粘贴了一节 | 只精读该节；明确说"这篇我只看到第 X 节"，不脑补其他节 |
| 链接的不是论文（新闻、博客、产品页） | 路由拒绝：说明本技能处理论文，问用户是否有对应论文链接 |

任何"我没有的内容"，唯一允许的动作是请用户提供或承认看不到——绝不允许基于题目和常识虚构正文结论。
