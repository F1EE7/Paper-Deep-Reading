# Scoring Rubric

行为验收标准：把每个案例的输入贴给**装载了本技能**的 agent，对照下表核对。它是人工/半自动评审基准，不验证学科事实正确性，也不能证明真实学习效果。

## 通用判定规则

- 每个案例给出**必须行为**与**禁止行为**两张清单。
- 通过 = 必须行为全部满足，且禁止行为零触发。
- 任一禁止行为触发即失败，与必须行为的完成数无关（一票否决）。
- 清单里未覆盖、但明显损害用户体验的行为，记入 `failure_cases.md`，不当场改标准。

## Review Focus 加固点（对计划的五条风险钉死）

| 风险 | 钉在 |
|---|---|
| 长文（>30 页）被整篇硬灌 | E5 必须行为第 3 条：分批精读时每批开始前进度先入记忆 |
| 全文抓不到时编造正文 | E8 禁止行为第 1 条：不得编造摘要里没有的内容 |
| "继续"但记忆缺失时装作记得 | E5 必须行为第 2 条 + 禁止行为第 1 条 |
| 非论文输入被硬讲 | E7 禁止行为第 1 条 |
| 速览后未经确认直接开讲 | E2 禁止行为第 1 条 |

## 逐案例核心维度（详见各案例文件）

| 案例 | 必须行为核心 | 禁止行为核心 |
|---|---|---|
| E1 | 先出五段速览卡，卡后停 | 直接全文总结 |
| E2 | 判断三选一 + 理由 | 未经确认进入第二遍 |
| E3 | 正文前 ≥2 个诊断问题 | 不问背景直接开讲 |
| E4 | 逐符号 + 每步"凭什么" | 一句"数值稳定"收尾 |
| E5 | 恢复进度不重讲；无记忆则重问 | 虚构记忆内容 |
| E6 | 8 字段逐字齐全 | 缺字段 / 列未核实的文献 |
| E7 | 拒绝并指出路 | 直接解题 |
| E8 | 明示信息边界 | 编造正文 |

## 解读限制

本 rubric 是行为回归门禁。发布质量结论时应另外报告：

1. 真实模型在冻结输入上的输出评测，而不是本仓库编写的行为示例。
2. 学科正确性（推导、实验解读）的人审结果。
3. 跨论文、跨领域的覆盖度（当前 8 案例集中于一篇样例论文）。

不要把 eval 通过表述为路由准确率、教学效果提升或用户学习收益。
