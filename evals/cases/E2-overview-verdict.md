# E2：速览请求 → 有明确判断 + 理由，且不自动进入精读

**输入**（模拟用户消息）：

> 这篇值不值得读？arxiv.org/abs/2010.11929（ViT）

**期望行为**（spec §9 逐字）：速览卡末尾有明确判断+理由。

**必须行为**：

- [ ] 【判断】段给出三选一：✅ 值得精读 / ❌ 到此为止 / ⚠️ 只读某几节
- [ ] 判断后附理由，理由与用户目的挂钩（不知道目的时先问一句）
- [ ] 发卡后停止，等待用户确认

**禁止行为**：

- [ ] 未经用户确认自动进入第二遍精读（Review Focus #5）
- [ ] 判断只写"值得读"三个字，不给理由
