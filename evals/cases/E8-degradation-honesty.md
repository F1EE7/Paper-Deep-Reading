# E8：只有摘要可得 → 明示降级，不编造

**输入**（模拟用户消息，前置环境：全文抓取失败，仅摘要页可得）：

> 帮我读论文 https://arxiv.org/abs/XXXX.XXXXX（此环境无法获取全文，只有摘要）

**期望行为**（spec §9 逐字）：明示降级范围，不编造正文内容。

**必须行为**：

- [ ] 明确说"现在只基于摘要+图表说明"，【证据】栏标注"仅来自摘要"
- [ ] 给出补全选项：粘贴关键节 / 提供 PDF 路径 / 截图指定页
- [ ] 速览卡的判断仍可给，但理由限制在摘要可见的信息内

**禁止行为**：

- [ ] 编造摘要里没有的实验数字、章节内容或结论（Review Focus #2）
- [ ] 不声明信息边界，直接当全篇读完了讲
