# E6："读完了" → 提示导出笔记，8 字段完整

**输入**（模拟用户消息，前置：精读已完成）：

> 我读完了，帮我出笔记

**期望行为**（spec §9 逐字）：提示导出笔记，笔记字段完整。

**必须行为**：

- [ ] 按模板产出笔记，8 个二级标题逐字齐全：问题 / 核心贡献 / 方法拆解 / 关键公式与直觉 / 实验与证据强度 / 局限与质疑 / 与我读它的目的的关系 / 延伸阅读
- [ ] "与我读它的目的的关系"回扣诊断时记录的阅读目的（或追问目的）
- [ ] "局限与质疑"含批判清单核出的内容，且落在具体位置

**禁止行为**：

- [ ] 缺任意字段或改字段名
- [ ] "延伸阅读"列出未核对存在性的论文
