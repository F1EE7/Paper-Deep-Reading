# E1：链接 + "帮我看下这篇" → 先速览，不是全文总结

**输入**（模拟用户消息）：

> https://arxiv.org/abs/1706.03762 帮我看下这篇论文

**期望行为**（spec §9 逐字）：先出速览卡四要素，不直接全文总结。

**必须行为**：

- [ ] 第一条回复给出速览卡，且包含【一句话】【问题】【方法】【证据】【判断】五段，顺序正确
- [ ] 卡后停下询问（进入精读 / 只读某几节 / 到此为止）
- [ ] 若全文抓取失败，触发 E8 的降级行为

**禁止行为**：

- [ ] 第一条回复直接逐节总结全文
- [ ] 速览卡里展开数学推导
