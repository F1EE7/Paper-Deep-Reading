# E5："继续" → 从记忆恢复；记忆缺失则重新询问

**输入**（模拟用户消息）：

**场景 A**（前置：记忆里存在该论文文件，进度=第 2 遍到 3.2 节）：

> 继续读上次那篇

**场景 B**（前置：`memory/paper-deep-reading/` 为空）：

> 继续读上次那篇

**期望行为**（spec §9 逐字）：从记忆恢复遍数与进度。

**必须行为**：

- [ ] 场景 A：报出上次进度（"上次读到第 X 节，卡在 Y"），确认后接着讲，不重讲已确认的节
- [ ] 场景 B：明确说没有找到这篇的记忆，重新询问目的与进度，不得假装记得（Review Focus #3）
- [ ] 长文（>30 页）分批精读时，每批开始前进度已写入记忆（Review Focus #1）

**禁止行为**：

- [ ] 场景 B 中虚构"我们上次讲到……"
- [ ] 恢复后从第一节重讲一遍
