# E4：单个公式讲透 → 逐符号推导链

**输入**（模拟用户消息，前置：已读到 3.2 节）：

> 公式 (1) softmax(QK^T/√d_k)V 这个公式给我讲透，为什么要除以 √d_k？

**期望行为**（spec §9 逐字）：逐符号解释+推导链，引用上下文。

**必须行为**：

- [ ] 每个符号（Q、K、V、d_k、softmax）单独解释，给直觉
- [ ] 对"为什么除以 √d_k"给出推导链：每步一句"凭什么"（方差随 d_k 增长 → softmax 饱和 → 缩放归一）
- [ ] 引用论文上下文（该公式是 3.2 节核心算子；论文只在脚注给了假设）

**禁止行为**：

- [ ] 只说"为了数值稳定"就收尾，不展开
